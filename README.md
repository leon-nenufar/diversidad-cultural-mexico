# Diversidad cultural en México — versión visual

Sitio estático listo para GitHub Pages.

## Mejoras de esta versión
- Pintura histórica de castas como referencia visual.
- Diagrama explicativo simplificado del sistema de castas.
- Infografía oficial/educativa enlazada sobre el origen de la LSM.
- Diagrama visual de los componentes comunicativos de la LSM.
- Fotografías históricas/culturales sobre mexicanos en Los Ángeles.
- Diagrama de identidad transnacional.
- Créditos y licencias visibles.

## Publicar
Sube todo el contenido del ZIP a la raíz de un repositorio de GitHub. Después activa:
Settings → Pages → Deploy from a branch → main → /(root).

Las fotografías e infografías de Internet se cargan desde sus fuentes remotas; los diagramas SVG sí están incluidos dentro de `assets/`.
